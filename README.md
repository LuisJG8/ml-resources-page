# ML Resources Page

A standalone React/Vite learning path and resource library for classical machine learning.

## Development

Use Node.js 24 (see `.node-version`). Run `npm ci`, then `npm run dev`.

## Validation

Run `npm test` and `npm run build`. GitHub Actions runs both on every pull request and on `main`.
Build output is a standard static `dist/` directory. No backend, API key, or hosting integration is required.

The foundation includes local Manrope typography, shared curriculum data, accessible scroll reveals,
and progressive image-loading utilities. Subsequent feature PRs add the pipeline, study pages,
resource library, and resource chooser.
